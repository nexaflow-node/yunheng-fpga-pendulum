# 开发历程：从建模、仿真到定版（2026-10-11 → 10-31）

按真实推进顺序记录。每一步都有数据支撑，否定一个方向和得到一个结论同样有价值。
配套的坑与教训见 [踩坑清单.md](踩坑清单.md)，仿真模型与结论见 [../sim/](../sim/)。

---

## 第 0 阶段：建模与工具链（10-11 起）

- 平台：J280 旋转倒立摆套件 + 高云 GW2A-LV55PG484C8/I7，50 MHz，控制节拍 1 kHz。
- 用官方给的机构参数（摆杆/旋臂均 152 mm、90 g）建立 LQR 模型；增益只能从官方数据算
  ——级联 PID 直接套网上流传的增益，电机"根本摆不动"。
- 建立采集链路：板内 896 bit × 2048 条轨迹缓冲，62.5 Hz 抽稀，串口回传 CSV；
  上位机 MATLAB 解析。采集链路本身后来踩了两个坑（见踩坑清单 C/F 类）。

## 第 1 阶段：离线模型的三次打脸（10-11 → 10-22）

1. **模型不同构**：旧离线模型的增益、BD、积分项与 RTL 实际全不一样，据此做的推断全部无效。
   → 仿真参数必须从 RTL 源文件直接解析。
2. **极点符号算反**：教科书 u=−Kx，RTL 用 u=+Kx，闭环矩阵应是 A+BK。算出 |z|=1.18 的
   "假不稳定"，一度以为设计本身错了。
3. **仿真对增益没有区分度**：48 组真实捕获态喂进仿真，四种增益变体全部存活；
   仿真预测的最优增益实测并不优。0A9（加大 KQ_2）仿真说最好、实机全部捕获失败。
   → 仿真能验符号、稳定性、频带结构；不能用它排增益。

## 第 2 阶段：校准过的仿真（10-23 → 10-24，sim075）

6 状态非线性模型 + 实测摩擦（起动 2.30/2.15 V、运动摩擦 0.72 V、驻留相关）+
传感器量化，与 075A 实测对照校准（duty 均值 112‰ vs 实测 113‰）。三轮结论：

| 轮次 | 结论 |
|---|---|
| 一 | 纯偏置 C=2.3 V 在无噪声仿真里"大幅改善"——后来加上编码器噪声后同样发散，复现了 102 的实机失败。**静摩擦在替环路滤掉传感器噪声**，不能全去掉 |
| 二 | 旧套件上 KQ_0=538 近最优、KQ_1=315 是甜点；起动阈值决定极限环幅度（2.3 V→臂 15°，1.4 V→8°） |
| 三 | 驻留依赖摩擦建模 →"保松"脉冲路线，实机否决（谷底 20–100‰ 本来就是滑动中的动摩擦） |

仿真模型的用途边界就此固定：验符号、验稳定性、排除法；增益排序必须上板。

## 第 3 阶段：旧套件调参与 085 定版（10-22 → 10-24）

- 075 → 085 血统：陷波 8.5 Hz、零点修正（3100→3068~3074）、关 8 s 重锚（离散 18°→4°）。
- 085 好侧实测：臂峰峰 32.5°、θRMS 3.38°、滑脱 0、duty 10–25 Hz 能量 93‰（全场最安静）。
- 同期试过并否决：死区补偿（034/101/102/079–082 全败）、持续/单脉冲释放、扇区零点补偿、
  臂速死区（慢摆翻倍）、宽陷波（慢摆翻倍）。

## 第 4 阶段：PID 路线与"聪明方案"大否决（10-25 → 10-30）

做出来跑过、再被数据否掉的一批（详见踩坑清单 E 类）：

| 方案 | 结局 |
|---|---|
| 级联 PID（0A1） | 套用外部增益根本摆不动；增益只能从官方惯量算 |
| PID 公平重测（0K0，位置积分 Ki=120） | 24 s 跌倒；积分 69% 时间钉钳位、与误差相关 +0.48（助推）→ **位置积分正式终结** |
| 分状态增益（0J0/0J1） | 用抽稀 trace 定阈值，实际占用 49% 而非 4%；切换阶跃把 duty 10–25 Hz 从 219 灌到 270‰ |
| 位置低通 10/20 Hz | 10 Hz 相位越界跌倒；20 Hz 衰减不足无收益 |
| 单脉冲/持续释放 | 驻留条件不成立 / 摆幅 44° 滑脱 5 次 |

**核心结论（旧套件）：摆幅与抖动是同一个旋钮的两端。** duty 10–25 Hz 能量 085 的 93‰ →
一路涨到 305‰，对应臂摆 29.5°→13°，没有一版同时做到低摆幅+低震动。

## 第 5 阶段：机械觉醒（10-21 起反复）

- 螺丝松紧是最大单项：松着跑"历史最好"是假象（机械柔性滤掉了臂的黏滑），拧紧后 N3 同固件
  臂峰峰 19.7°→60.9°；能量没消失，只是变成 45–60° 大极限环。**拧紧状态下正确的旋钮是阻尼。**
- 桌面调平（>0.5° 必须垫）+ 全部螺钉复紧，起摆成功率直接到 ~100%。
- 电位器零点随臂角做 ±3° 正弦漂移（拟合 raw = 3072.83 − 5.68cos a − 38.63 sin a），修不掉，
  只能接受；这解释了"每个版本最佳零点不同"。
- 1908 次黏滑事件统计：起动 duty 中位 274‰（p10/p90=143/408‰），满量程只有 500‰——
  **这台机械上控制侧的天花板由摩擦决定，不是参数。**

## 第 6 阶段：新套件一日定版（10-31）

换实验室新套件（摩擦特性不同，085 起摆失败）。

| 版本 | 改动 | 结果 |
|---|---|---|
| N2 | 起摆强化：耐心 60 s、软限位 ±145°、臂阻尼 0.25 V/(rad/s) | 能起摆，平衡差（臂 52–60°） |
| N3 | 零点 3061 | **最大单项收益**：臂 55°→19.7°，θRMS 1.28° |
| N4/N5 | KQ_0 750/1000 | 更差（56.6°）——位置刚度加剧黏滑 |
| N6 | KQ_1 450 | 臂 15°，θRMS 1.11° |
| N7–N9 | 陷波迁移 | 新套件主峰 7.8–16.8 Hz 漂移，8.5 Hz 对不上 |
| N10–N12 | KQ_1 550 + 宽陷波 12.5/12 | σ 降到 84‰ |
| N14 | 窄陷波 9.5 Hz | 打地鼠：3–8 降但 12–18 反弹 240‰ |
| N15–N20 | 观测器带宽 | **唯一全频段降压的旋钮**：15→10.5 Hz，σ 83→71 |
| **N21（定版）** | KQ_1 650 + 观测器 10.5 Hz | 臂峰峰 15.7/15.7/17.7°，θRMS 1.60/1.56/2.15°，σ 59–92‰，零触轨 |
| N22/N23 | KQ_1 750 / 观测器 7.5 Hz | 两个方向的边界：失稳 / 滞后吃掉收益 |

启动链路的坑同日修复：SW3 长按 1.5 s 不可靠 → LONG_MS=800，此后采集稳定。

## 第 7 阶段：拓展功能与跌倒恢复（10-31 下午）

- 三点点位 0°/+30°/+60°（参考 10°/s 平滑移动）+ 整圈旋转（21.0°/s，走满 360° 就地重锚）：
  实测 30 s 累计 385°，|θ|≤9.5°、RMS 2.2°，零触轨。旋转上限由 12° 保护区决定，不是电机。
- 大角度保护：|θ|>12° 时 KQ_1 650→315（用户反馈"被推动后容易加速失稳"的对策）。
- 跌倒自动重起：|θ|>40° 立即切断（救不回来，继续追只会撞限位）→ 摆杆垂下稳定 1.5 s →
  自动重新起摆；只有故障码 2/6 可恢复，其余锁死。现场多次复现通过。
- N32：仅把运行时长上限 30 s→65 s（`MAX_RUN_MS`），供拍摄视频；上限设 300000 会让 16 位
  计数器扩位、SETUP 掉到 +0.195 ns，故取 65535。

## 一句话复盘

> 先机械（水平/紧固/零点）→ 再验证模型与 RTL 同构 → 每版一个变量 → 每版至少两跑 →
> 发版前看 SETUP 余量 → 拿数据先验固件 ID 和统计口径。
> 控制侧的天花板由摩擦决定；观测器带宽是唯一能全频段降压的旋钮；跌倒时切断比追摆更好。
