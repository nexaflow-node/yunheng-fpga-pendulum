## 物理解读
- 全偏置（C≥起动值）下臂**永不静粘**，摩擦只剩动摩擦（0.72 V），环路近似线性 → 一切变好。
- 半偏置最危险：仍在起动阈值附近黏滑，但多了滞后。
- 101 失败的根因不是"加补偿"这个思路，而是 PWL 在 ±50‰ 处的 **5× 斜率**。

## 建议的下一版（4A575102，单一改动）
在陷波/输出**之后**加纯偏置：`duty_out = duty + sign(duty)*235`（2.3 V/12 V*1000，
比起动均值 2.15 V 略高），**无斜率变化、无膝点**。duty 限幅与 60‰/ms slew 照旧。
风险：零点附近 ±2.3 V 交替 => 电机嗡鸣/发热；仿真无法评估温升，需上板听/摸。
判据：slip 0、臂 ≤10°、θ ≤1.2°、duty |avg| <60‰；若嗡鸣不可接受，回退并改用
"观测器估计库仑项"路线。

# 第二轮：修掉"冻结"近似后的结论（2026-10-24 凌晨）

## 102 失败的仿真复现与根因
- 加上真实的编码器边沿抖动（2 counts rms）后，**纯偏置 2.3 V 在仿真里同样发散**——
  与实机 102 一致。机制：偏置让臂"永远在动"，编码器量化噪声不再被静摩擦挡住，
  直接变成 1 kHz 的真实力矩噪声灌进环路。
- **静摩擦在干一件有用的事：替环路滤掉传感器噪声。** 完全移除它（全偏置）= 拆掉滤波器。
- 未加噪声的旧仿真预测"偏置很好"是模型缺陷，已修正。

## 参数边界（含噪声模型，多组验证）
| 项 | 边界 |
|---|---|
| KQ_0 | 538 已近最优：650/800/1000 单调变差，1300 发散 |
| KQ_1 | **315 是甜点**：250 臂 +13°，380 发散（与 2.5 Hz 墙一致） |
| 小 dither（0.3–0.9 V @37.5 Hz） | 不发散但无突破（臂 12–31°） |
| **起动阈值本身** | **决定极限环幅度**：2.3 V→臂 15°；1.8 V→9.2°；1.4 V→8.0°/θ 1.30°；1.0 V→θ 0.98° |

## 最终结论
控制侧（增益/陷波/参考/补偿）在这个机械上已经**全部到顶**：538/315/4690/450 就是
当前摩擦水平下的最优。仿真里唯一能把臂 15°→8°、θ 2.3°→1.0° 的变量是
**把起动阈值从 2.3 V 降到 ~1.0–1.4 V**——这只能在机械侧实现（齿箱/输出轴润滑、
皮带/联轴器预紧、换润滑脂）。这与 4A575055 慢速试验"起动 170–223‰"完全对应：
**当前极限环幅度 ≈ 起动阈值 / KQ_0 等效刚度**，降阈值=直接降极限环。

## 给实机的前两件事（不动固件）
1. 齿箱与输出轴重新润滑（薄层锂基脂或含油轴承油），目标是慢速试验的起动 duty
   从 170–223‰ 降到 ≤100‰（用 4A575055 慢速固件直接量）；
2. 量完再跑 100，臂行程应该自己从 ~15-25° 掉到 ~10° 附近——如果掉，机械路线确认。

# 第三轮：驻留依赖摩擦 + 间歇"保松"脉冲（2026-10-24，重大发现）

## 新模型要素（全部来自 4A575055 慢速试验的实测数据）
**驻留依赖起动阈值**：滑动后齿隙"松"（起动阈值降到 trough 20–100‰），
静止驻留后重新"紧"（回升到 170–223‰），时间常数 ~0.5 s。
此前所有仿真都用了常数 2.3 V，漏掉了这个真实特性。

## 仿真结果
| 方案 | 臂 | θRMS | 6–10 Hz | duty\|avg\| |
|---|---|---|---|---|
| 常数阈值（旧模型） | 13.4–15.5° | 2.3–2.7° | 0.35 | 112 |
| 驻留模型，无脉冲 | 21.1° | **1.20°** | 0.07 | 70 |
| **驻留模型 + 保松脉冲 1.2 V/0.4 s** | **0.1–0.4°** | **0.09–0.14°** | 0.07 | **13–23** |

鲁棒性：5 个种子 × 2 档编码器噪声 × 大扰动（vth0=30°/s）全部收敛到同一水平，
无发散。

## 与 102 失败方案的本质区别
- 102 纯偏置：**每个非零 tick 都给 ±2.3 V** → 臂永远在动 → 传感器噪声直接变
  力矩噪声 → 发散（实测+仿真一致）。
- 保松脉冲：**平时照常卡死**（静摩擦继续滤噪声），每 0.4 s 只加 **一个 tick**
  的 1.2 V——恰好在"刚松开"的低阈值上推开一小步，然后重新卡死。
  噪声滤波保留，臂逐步爬向 θ=0 平衡点。

## 实现方案（4A575080，基于 076 结构）
`c_balance_core.v` 输出级后加三行状态：
```
stick_dwell: 卡死时计数（ms），臂一动清零
pulse_due:   stick_dwell >= 400
duty_out = duty + (pulse_due ? sign(duty 或 sign(theta))*276 : 0)   // 1.2V
```
只注入一拍（1 ms），然后 pulse_due 清零重新计时。其余一切不动。
注意 trace 的 duty_permille 会包含脉冲（±276 的尖峰每 400 ms 一次）——
分析时要识别（|duty|≈276 且孤立）。

## 验收判据（上板）
1. 15–30 s 臂 p2p **≤8°**（仿真 0.1–0.4°，留余量）；
2. θRMS **≤1.0°**；
3. 6–10 Hz duty 不涨（≤140‰）；
4. 若每 400 ms 能听到轻微"哒"声属正常（脉冲在工作）；若出现持续嗡鸣或
   高频颤 → 回退 076。
