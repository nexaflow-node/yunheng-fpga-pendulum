# 云衡实时姿态控制系统 — 基于 FPGA 的旋转倒立摆

2026 年全国大学生嵌入式芯片与系统设计竞赛 · FPGA 赛道 · 选题一 ｜ 参赛队编号 **43798**

高云 GW2A-LV55PG484C8/I7（GW2A-55C，484 引脚）@ 50 MHz，控制节拍 1 kHz，全部控制逻辑用 Verilog 实现。

## 四、编译

1. 把 `01_rtl_final_N21/` 拷到**纯英文路径**（如 `C:\j280n21`）——高云 IDE 遇中文路径报 SP0002；
2. Gowin EDA V1.9.12.03，新建工程，器件选 `GW2A-LV55PG484C8/I7`，顶层 `j280_c_top`；
   或直接 `gw_sh build_w0.tcl`；
3. 产物：`impl/pnr/j280_k290_w0.fs`；
4. 发版前检查 `impl/pnr/*.timing_paths` 的 SETUP 余量（本项目门槛 >0.3 ns，定版 +1.284 ns）。

## 五、烧录与运行

1. Gowin Programmer → 选 `05_firmware/J280_fs_N21_定版_4A575194.fs` → 烧到配置 Flash；
2. 桌面调平、螺钉复紧；上电后**不要按 SW1**（会覆盖 3061 零点）；
3. 摆杆自然垂下，**按住 SW3 约 0.8 s 松手**启动；跑满 30 s 自动停机，故障码 7 表示正常结束。

## 九、说明

- 轨迹缓冲每 16 ms 记录一条，30 s 满 1875 条；不采集不影响控制。
- 上位机脚本里硬编码了增益与零点，换固件必须同步改（`K_q8`、`fixed_up12`），否则一致性校验失败、采集无数据。
- 演示版 N32 只是把运行时长上限放到 65 s（`MAX_RUN_MS`），控制律与定版完全一致，仅用于拍摄演示视频。
